# Práctica 3: CloudMonitor SPA - Dashboard de Métricas

Este repositorio contiene la implementación de una Single Page Application (SPA) enfocada en la monitorización de infraestructura en la nube 

## Requisitos 
* Navegador web moderno (Chrome, Firefox, Edge o Safari) con soporte para CSS Grid
* Para servidor local: Visual Studio Code con Node.js v18.0 o superior.

## Instalacion y Ejecucion Local
Si ya tiene instalado Node puede saltar al paso 3

1. Puedes descargar e instalar la versión recomendada (LTS) directamente desde el sitio web oficial: https://nodejs.org/. 

2. Una vez instalado, abre tu consola de terminal (CMD o PowerShell) y verifica que esté correctamente configurado ejecutando: node -v

3. Clonar el Repositorio e Instalar Dependencias: abre la terminal y navega hasta la carpeta del proyecto da clik en descarga e instala las dependencias necesarias: npm install

4. Inicia el servidor ejecutando: npm start

4. Acceso a las Rutas en el Navegador

5. Una vez iniciado el servidor en el puerto 3000, puedes acceder a la pagina web desde el navegador por el link correspondiente a cada verision:

CloudMonitor: http://localhost:3000/
